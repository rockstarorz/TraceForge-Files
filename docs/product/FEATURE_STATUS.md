# TraceForge 功能实现状态表

核对日期：2026-10-10。正式发布基线为 **V0.3.19.1**，本地开发主线为 **V0.3.19.1-optimal**（检查点 `90a8eba`）。该 optimal 版本的现有未发布修改已全部保留，后续不再从 V0.3.18 建立并行长期维护线。

## 状态定义

| 状态 | 含义 |
| --- | --- |
| 已上线 | 已进入正式 Release，可按当前说明使用 |
| 试验性上线 | 已提供给用户，但协议变体或样本覆盖仍有限 |
| 部分上线 | 底层数据或基础入口已存在，尚未形成完整用户功能 |
| 本地开发中 | 已修改本地源码，尚未随正式 Release 发布或仍需实机验证 |
| 计划中 | 已确认有价值，尚未实施 |
| 评估中 | 是否接入、范围和成本尚未确定 |

## 维护规则

- “字段已经解析”不等于“用户功能已经完成”。只有具备入口、展示、口径说明和基本验证后，才标记为已上线。
- 试验性协议能力必须保留试验性标识，并记录使用过的设备和日志变体。
- 状态变化应同时更新本表、用户版 README、开发说明和对应 Release Notes。
- RC 期间只接收阻断性或核心结果错误修复；新功能进入后续开发版本。
- `dist/releases/` 是唯一发布包目录；`build/` 不再保存正式源码工作树。
- 真实日志包含客户、设备和位置数据，不得直接提交到公开仓库。
