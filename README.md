# TraceForge Files

TraceForge 的私有产品文档仓库，用于独立维护产品需求、功能实现状态和后续版本规划。这里不存放应用源码、客户日志、设备标识、坐标、密钥或公司内部产品资料。

## 文档入口

- [产品需求文档](docs/product/PRODUCT_REQUIREMENTS.md)
- [功能实现状态表](docs/product/FEATURE_STATUS.md)

## 维护规则

1. 新需求确认后写入产品需求文档；仅供讨论的参考资料不得直接转化为正式需求。
2. 开始实现、进入试验版本和正式发布时，同步更新功能状态表。
3. 每次更新在提交说明中写明需求、状态或版本变化。
4. 上传前检查客户信息、真实日志、设备标识、坐标、内部资料和访问凭据。
5. 本仓库保持私有；若未来需要对外分享，应另行生成脱敏版本。

- 后续建议：先验证 V0.3.19.2-rc.1，通过后提升为 V0.3.19.2
